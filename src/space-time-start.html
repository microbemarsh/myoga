Space-time observations

Stack observed sample locations through collection time. Inspect date uncertainty, compare metadata, and optionally overlay a bounded graph of genomic neighbors.

Requires a sample ID, coordinates and collection dates. Standardized myoga columns are recognized automatically.
Metagenomic communities (optional) Choose a flat folder of per-sample summary reports, not per-read classifications. Filenames should match sample IDs, for example S01.kreport. Alternatively, add a kraken_report filename column to metadata. All uploaded basenames must be unique. Do not combine this input with a genomic distance matrix.
Column overrides & distance label

Files are processed only by your local myoga process. The resulting download opens without a server or network. Browser uploads are limited to 256 MiB; use the CLI for larger files. Date-less samples remain available in the ordinary map.
